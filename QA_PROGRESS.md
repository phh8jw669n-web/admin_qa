## Setup blockers found (all worked around)

- Backend `npm ci` failed: 6 lockfile entries point to `registry.npmmirror.com` (403). Fixed in the lockfile (BE-CHG-001, bug in `qa_backend/bugs.csv`).
- No backend `.env.example`. Created `admin_backend/.env.example.qa` with dummy values.
- Frontend Vite proxy points to a hard-coded public IP. Made it overridable with `QA_API_PROXY_TARGET` (FE-CHG-001).
- S3/SES are off (`AWS_ENABLED=false`): no real emails or uploads. File endpoints return 503, so 2 cross-tenant file checks are Blocked.
